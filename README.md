## ✨ Fitur Utama

- 🌌 **Sleek Dark Mode & Neon Gradient**: Estetika futuristik beraksen Neon Cyan & Cyber Purple dengan *ambient background glow*.
- 💎 **Glassmorphism UI**: Kartu transparan dengan efek `backdrop-filter: blur(20px)`, bayangan halus, dan glowing hover elevation.
- ⚡ **Simulasi Chat AI Interaktif**: Demo eksekusi AI real-time dengan efek animasi ketik (*typing effect*), indikator pemrosesan cerdas, serta hasil preview dokumen laporan penjualan instan.
- 📐 **CSS Grid 3 Keunggulan**:
  1. **Layanan 24/7**: Penanganan ribuan respon serentak tanpa jatah henti 365 hari.
  2. **Integrasi Seamless**: Kompatibel dengan sistem lama (CRM, ERP, WhatsApp API, Slack, Google Workspace).
  3. **Efisien & Hemat**: Mengurangi biaya operasional hingga 60% dan payback period < 3 bulan.
- 🎯 **Layanan Kustom**: 4 Solusi AI spesifik industri (Customer Support, Workflow & RPA, Sales Outreach, Executive Reporting).
- 📱 **100% Responsif**: Dioptimalkan dari smartphone (320px) hingga monitor layar lebar (1440px+).
- 🏷️ **Kode Semantik & SEO-Friendly**: Menggunakan tag HTML5 semantik, meta description, dan Open Graph ready.

## 📂 Struktur File

```text
├── index.html       # Struktur HTML semantik utama
├── style.css        # Desain sistem, warna neon, glassmorphism, dan responsivitas
├── script.js        # Logika interaktif: simulasi chat, typing animation, dan navbar blur
├── standalone.html  # Versi mandiri all-in-one (HTML, CSS, dan JS dalam satu file)
├── dev-server.js    # Server lokal Node.js port 3000 untuk pengujian dev
├── vercel.json      # Konfigurasi deployment routing Vercel
├── README.md        # Dokumentasi repositori & link deploy
└── .gitignore       # Aturan pengabaian file Git
```

---

## 🚀 Cara Menjalankan Secara Lokal

### Menggunakan Node.js Server:
```bash
node dev-server.js
```
Lalu buka peramban web di: `http://localhost:3000/`

### Atau Buka Standalone File:
Buka langsung file `standalone.html` pada browser apa pun (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari) tanpa perlu menginstal dependensi.
